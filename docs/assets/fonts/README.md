# Web fonts

The documentation site self-hosts a small Latin subset of its type system so
the interface does not depend on a third-party font request at runtime.

| Family | Source package | Files used | License |
| --- | --- | --- | --- |
| Space Grotesk | `@fontsource-variable/space-grotesk@5.3.0` | variable normal Latin WOFF2 | SIL Open Font License 1.1 |
| IBM Plex Sans | `@fontsource-variable/ibm-plex-sans@5.3.0` | variable normal Latin WOFF2 | SIL Open Font License 1.1 |
| IBM Plex Mono | `@fontsource/ibm-plex-mono@5.3.0` | 400, 500, and 600 normal Latin WOFF2 | SIL Open Font License 1.1 |

The complete license notices distributed with those packages are retained in
this directory. The fonts are not modified.
